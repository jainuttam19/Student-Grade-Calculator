# Student Grade Calculator

A simple calculator built using C++.

## About the Project
This project performs basic mathematical operations using a C++ program.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division by zero handling
- Invalid operator handling

## Technologies Used
- C++

## How to Run
1. Download or clone this repository.
2. Open `main.cpp` in a C++ compiler.
3. Compile and run the program.
4. Enter two numbers and an operator.

## Sample Output

```text
===== CALCULATOR =====
Enter first number: 20
Enter operator (+, -, *, /): *
Enter second number: 5
Result = 100
```
